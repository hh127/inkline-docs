## 能力范围

VBA 版是功能全集基线，主线 JS 版的业务语义基本由它承接而来：

| 能力 | 说明 |
| --- | --- |
| 实时审计与时间线 | `ThisWorkbook` 事件捕获，批注内留痕 |
| 变色与括号层级 | 按方头括号与圆括号层级着色 |
| 字符级差异 | LCS 引擎 + 算量变化量 |
| 沉浸阅读 | UserForm + WebBrowser 渲染 |
| 算式求值 | `Application.Evaluate` |
| 单元格函数 | `JS()` 形式的 UDF |
| 统计大屏 | 可落盘 HTML，ECharts CDN |
| 隐私金库 | `Vault_` 隐藏表 + 掩码 + 密码保护（非密码学加密） |
| 导出审查版/交付版 | 副本清洗、公式静态化 |
| 一键导入旧表 | 多选窗体、配置继承 |
| 清除审计标记 | 分级清理，保留用户批注 |
| 表内悬浮按钮 / 快捷键 | VBA 版特有，JS 版有意不做 |

## 修复与性能（冻结前最后一批）

- 配置缺失或非法时回退安全默认值，不再让空配置中断加载；
- 隐私遮蔽失败不再静默标记为「已加密」；
- 清除审计标记不再强制打开事件与屏幕刷新；
- 高亮引擎跳过无需重置的纯数字格；清除审计底色改批量写回；
- 配置同步缩小清理范围并批量备份旧参数；
- 审计批注换行兼容 CRLF/CR，作者名解析修正；
- 导出逐表重置公式搜索区域，失败时清理临时文件并还原计算模式。

## 冻结口径

- 不再接受功能变更，仅维护文档与明显的安全、数据正确性问题说明；
- 后续能力以 WPS JS 主线为准，见[4.67](/changelog/v4.67.html)；
- VBA 版与 JS 版的差异（表内按钮、快捷键、大屏落盘等）统一在[双实现能力矩阵](/dev/parity.html)维护。

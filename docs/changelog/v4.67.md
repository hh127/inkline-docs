## 本版能力

### 审计与复核

- 实时审计链：每次单元格改动自动留痕，批注内保留「未审计前原值」基准点，保留条数可配置且**不截断基准点**；
- 时间线面板：按修改时间倒序展示，可回滚单条记录；
- 字符级差异：自研 LCS 引擎，红绿高亮到字符，并联动算量变化量；
- 沉浸阅读：算式拆成 4 级括号配色的可读结构，中文注释转胶囊，点击折叠回计算值。

### 计算与单元格

- 自研求值引擎：清洗中文、全角括号与无前导 0 小数后安全求值，幂按左结合对齐 `Application.Evaluate` 语义；
- 单元格函数 `=Z.JS()`：`wps.AddCustomFunction("Z","JS",fn)` 注册，与主引擎由构建期指纹守卫对齐，防结果漂移；
- 全表批量变色：范围 ∩ UsedRange、按 5 万格分块、筛选态防护。

### 交付与安全

- 隐私金库：`Vault_` 隐藏表 + 掩码 + 密码校验；批量加密/解密支持一次密码与状态清单；
- 导出双轨：内部审查版（保留最近 N 条日志、恢复手工批注）与外部交付版（物理剥离加密表、公式静态化）；
- 一键导入旧表：编号多选、整表复制、旧配置按表名/参数名对位合并；
- 清除审计标记：机器日志删除、用户批注保留、纯手工批注不动；
- 广联达导出表清洗：9 个开关的纯函数流水线，原地应用可回退。

### 平台能力

- 项目管理四动作：生成 / 删除 / 启用 / 停用（软启停，配置表保留可随时恢复）；
- Ribbon 五组：项目管理、视图与审查、状态控制、数据清洗、交付与安全；
- 任务窗格面板 + 统计大屏（ECharts 5.5.0，iframe 隔离渲染）。

## 修复

- Ribbon `toggleButton` 回调参数顺序：WPS 传参与 Office 标准相反，改为遍历实参找带 `Tag` 的 control，开关按钮点击不再静默失效；
- 宿主 COM 桥方法探测陷阱：WPS 下方法 `typeof` 为 `unknown`，去掉 `typeof === "function"` 判定，解锁与撤销恢复生效；
- 批注写入自校验：`Comment.Text` 在部分桥下静默失败导致批注只停在首条，改为回读校验 + 删除重建；
- 批注换行兼容：统一按 `\r\n` / `\r` / `\n` 切行，时间线不再空白；
- 跨工作簿切换时 Ribbon 按压态串台：切换点重载配置并触发 `Invalidate`；
- 公式静态化失配：补齐单元格引用解析，避免交付后出现 `#NAME?`；无法内联时整格降级为计算值并回读校验；
- 外部交付版只剥机器日志、保留手工批注，防止清洗误删；
- 表结构删除竞态：删除前证明目标表消失再同步，避免配置表残留幽灵行。

## 性能

| 优化 | 效果 |
| --- | --- |
| 选区/配置/注册表矩阵化批量读 | 大选区拖拽与配置生成从逐格 COM 降为单次矩阵读 |
| 变色零 COM 初筛 + run 合并 | 空白/纯数字/公式格不触碰 `Characters`；中英文高亮段每格 1 次赋值 |
| 导出按列分块（面积 > 10 万格） | 大表导出避免内存峰值与宿主无响应 |
| 审计快照矩阵化 + 隐形批注幂等守卫 | 重复写同一格不再上千次 COM |
| 事件防抖与轮询兜底 | 选区防抖 180ms → 30ms 收窄，表结构同步原生事件为主、5s/10s 轮询兜底 |

## 破坏性变更

| 变化 | 影响 | 迁移建议 |
| --- | --- | --- |
| 表内悬浮按钮与快捷键体系移除 | VBA 版的表内按钮在 JS 版不可用 | 改用 Ribbon 与任务窗格，见[双实现能力矩阵](/dev/parity.html) |
| 单元格函数命名空间改变 | VBA `JS()` → WPS `=Z.JS()` | 旧公式需改写法，见[单元格函数](/features/custom-function.html) |
| 无 4.67 安装包 | 不能下载即用 | 按[安装（WPS）](/guide/install-wps.html)源码部署 |
| 大屏不再落盘 HTML | 改为任务窗格内渲染 | 需要归档时用浏览器打印/另存 |

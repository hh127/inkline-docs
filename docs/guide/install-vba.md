# 安装 · Excel VBA

适用于 **Microsoft Excel** 用户，对应 **v4.66 冻结版**（最后一个 VBA 制品）。

::: warning 冻结基线
`src/` 与 v4.66 制品已冻结（最后提交 2026-08-21），**不再新增功能**；新功能只在 [WPS JS 版](/guide/install-wps.html) 上迭代。
选择 VBA 版的理由通常是：单位仍以 Excel 为主、需要沿用已有的 v4.66 工作簿。
:::

## 前置条件

| 项目 | 要求 |
| --- | --- |
| Excel | 桌面版 Excel（Microsoft 365 / 2016+，32 或 64 位均可） |
| 宏安全 | 允许运行宏（见下文「启用宏」） |
| 文件 | `releases/智算墨斗v4.66.xlsm`（可选：`案例演示文件v4.66.xlsm`） |

::: danger 不建议用 WPS 打开 xlsm 长期使用
WPS 对 VBA 宏的支持与 Excel 存在差异，事件、窗体与 WebBrowser 控件行为都可能不同。
VBA 版请在 Excel 中使用；WPS 用户请安装 [WPS JS 版](/guide/install-wps.html)。
:::

## 步骤 1：下载制品

在仓库 `releases/` 目录下载：

- `智算墨斗v4.66.xlsm` — 功能本体
- `案例演示文件v4.66.xlsm` — 可选，用于先看效果

## 步骤 2：启用宏

打开 xlsm 后，如果顶部出现「安全警告：宏已被禁用」，按顺序处理：

1. 若文件来自网络：右键文件 → 属性 → 勾选「解除锁定」→ 确定，再重新打开。
2. Excel → 文件 → 选项 → 信任中心 → 信任中心设置：
   - **推荐**：把存放工作簿的文件夹加入「受信任位置」，以后打开不再拦截；
   - 临时方案：宏设置里选择「启用所有宏」（仅在你的受控机器上使用，不建议作为长期配置）。
3. 关闭并重新打开工作簿，点击「启用内容」。

## 步骤 3：首次运行

1. 打开工作簿，确认功能区/控制面板出现智算墨斗入口；
2. 点击「生成配置表」（或首次打开时按提示初始化），生成 `Admin_Config`；
3. 需要审计/变色的工作表，在配置表里把「是否开启审计 / 是否开启变色」设为开启；
4. 参考[快速开始](/guide/quickstart.html)完成一次修改与时间线查看（VBA 版的差异以窗体展示）。

## 能力范围

VBA 版包含审计链、变色、差异时间线、沉浸阅读、统计大屏、隐私金库、导出、导入等功能；
与 WPS JS 版的完整对照见[双实现能力矩阵](/dev/parity.html)。已知差异举例：

- VBA 版有**表内悬浮按钮 / 快捷键**，WPS JS 版有意不做，改用 Ribbon + 侧边栏；
- VBA 版有**大屏落盘**，WPS JS 版在任务窗格内渲染；
- WPS JS 版新增**广联达表清洗**等能力。

## 常见问题

| 现象 | 处置 |
| --- | --- |
| 打开后没有功能区/按钮 | 宏未启用，或文件处于「受保护的视图」→ 先关闭受保护视图再启用宏 |
| 改名/移动文件后功能失效 | VBA 事件依赖 `ThisWorkbook`，请始终从启用宏的 xlsm 打开，不要另存为 xlsx |
| 多台电脑协作后审计记录异常 | VBA 版基于本地事件与批注，避免共享工作簿（共享工作簿会关闭事件） |
| 另存为后丢失功能 | 宏必须保存在 `.xlsm`；另存为 `.xlsx` 会剥离全部代码 |

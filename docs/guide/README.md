# 使用指南

本栏目面向**实际使用软件的人**：造价/预算、结算审计、复核与商务管理人员。读完这一栏，你应该能独立完成安装、配置和一次完整的算量核对/审计留痕。

::: tip 不需要会编程
本栏目按「先讲人话、再讲细节」写：步骤照着点就行，命令和路径可以直接复制。
遇到看不懂的电脑词，先翻下面的[术语速查](#术语速查)；每页末尾的「相关源码」是给开发者看的，**可以跳过**。
:::

## 我该用哪个版本？

| 你的情况 | 建议形态 | 入口 |
| --- | --- | --- |
| 用 WPS 表格，想要最新功能（推荐） | **WPS 官方 JS 加载项 4.67** | [安装（WPS）](/guide/install-wps.html) |
| 只用 Microsoft Excel，且已有 v4.66 工作簿 | Excel VBA 4.66（冻结版） | [安装（VBA）](/guide/install-vba.html) |
| 要在单位内网给多人用 | WPS 加载项 + 内网静态服务 | [部署运维](/deploy/) |
| 只是评估、看看界面 | 先读[功能详解](/features/) | 无需安装 |

::: warning 版本口径
**WPS JS 4.67 是当前主线**，但仓库 `releases/` 里只有 **4.66 的 xlsm 制品**，尚无 4.67 安装包——4.67 需要按[安装（WPS）](/guide/install-wps.html)用源码部署。两代形态的能力差异见[双实现能力矩阵](/dev/parity.html)。
:::

## 三条学习路径

### 路径 A：15 分钟跑通（推荐先走这条）

1. [安装（WPS）](/guide/install-wps.html)：装好加载项，看到「智算墨斗」选项卡
2. [快速开始](/guide/quickstart.html)：生成配置表 → 启用 → 改一个单元格 → 看时间线
3. 遇到问题查[常见问题](/guide/faq.html)

### 路径 B：一小时建立完整认知

在路径 A 之后，按顺序读：

1. [核心概念](/guide/concepts.html)：配置表、审计链、金库、系统表
2. [配置表与控制台](/guide/settings.html)：开关、颜色、按表启用
3. [典型工作流](/guide/workflow.html)：算量核对 / 结算审计 / 复核交付
4. 按需读[功能详解](/features/)里的具体功能

### 路径 C：部署给团队用

直接看[部署运维](/deploy/)：本机调试模式 → 内网多人 → 升级回滚 → 排障。

## 你需要知道的三件事

1. **一切从「生成配置表」开始**。没有 `Admin_Config` 工作表，软件不会对任何表做变色、审计或统计；配置表是全局开关与按表开关的唯一入口。
2. **系统表不要动**。`Admin_Config`（配置）、`Log_Audit`（审计流水）、`Vault_*`（隐私金库）由软件维护，手改会被事件层拦截或回滚。
3. **功能按表生效**。生成配置表后，每张工作表在配置表里都有「是否开启审计 / 是否开启变色」两列；新加的表默认不开启。

## 术语速查

下面是全站高频词的白话解释。**看不懂某个词时回这里查即可**，不用记。

### 表格与数据（造价日常）

| 术语 | 白话解释 |
| --- | --- |
| 配置表 | 工作簿里多出来的 `Admin_Config` 工作表，存放全部开关、颜色与项目信息 |
| 系统表 | 软件自己用的表：`Admin_Config`（配置）、`Log_Audit`（审计流水）、`Vault_*`（隐私金库），**不要手动改** |
| 审计链 | 单元格每次改动写进批注的历史记录（原值/新值/修改人/时间），像一条改动流水账 |
| 基准点 | 审计链里最早那个「未审计前原值」，用于算核增核减，**永远不会被清掉** |
| 批注 | 单元格右上角的小红三角/备注框，审计记录就存在这里 |
| 变色 | 按括号层级与中文注释给算式着色，只影响显示，**不改公式和数值** |
| 金库 | 隐私模式下存放原表副本的隐藏工作表 `Vault_<表名>` |
| 掩码 | 隐私模式下把原表内容显示成 `******` 的处理 |
| 快照 / 历史快照 | 某一时刻保存下来的内容副本；「历史快照」指从时间线打开的旧版本视图 |

### 软件与界面

| 术语 | 白话解释 |
| --- | --- |
| 加载项 / 插件 | 额外装进 WPS 或 Excel 里、增加新功能的小程序；本软件就是加载项 |
| 功能区 / Ribbon | 表格窗口顶部那一排「开始 / 插入 …」按钮区；装好后会多一个「智算墨斗」选项卡 |
| 任务窗格 / 侧边栏 | 表格窗口右侧（或左侧）可以收起的面板，本软件的审计面板、阅读面板都在这里 |
| 面板 | 就是上面说的侧边栏窗口，用来点按钮、看时间线 |
| 开关 | 配置表里的「开启 / 关闭」选项；分全局开关和按表开关两级 |
| 单元格函数 | 能在单元格里直接写公式的函数，例如 `=Z.JS("3.5*2")` 直接算出结果 |

### 安装与运维

| 术语 | 白话解释 |
| --- | --- |
| 部署 | 把软件装到电脑上并配置好、能用的过程 |
| 源码 | 软件的原始代码文件；4.67 版目前要从源码自行构建，没有现成安装包 |
| 构建 / bundle | 把多个代码文件拼成一个可加载的大文件，等于「打包」 |
| 本地静态服务 | 在自己电脑上跑的一个小程序，专门把软件文件提供给 WPS 读取（默认用 `3888` 端口） |
| 端口 | 电脑上区分不同网络服务的编号，像房间号；`3888` 被占用时换一个即可 |
| 进程 | 正在运行的程序实例；「完全退出所有 WPS 进程」= 在任务管理器里确认 `wps.exe` 都没了，只关窗口不算 |
| 缓存 | 程序为了加速存下的旧数据；有时改了代码但行为没变，就是缓存没刷新 |

### 技术词（看懂个大概即可）

| 术语 | 白话解释 |
| --- | --- |
| 引擎 | 负责某件事的核心程序；「差异引擎」就是专门比对差异的那部分程序 |
| 宿主 | 运行插件的母程序，本项目里指 WPS 表格或 Excel 本身 |
| CDN | 从互联网上按地址加载公共资源的服务；断网时依赖它的图表会空白 |
| iframe | 网页里嵌套的独立小窗口；统计大屏就渲染在侧边栏里的这种小窗口内 |
| 命名空间 | 函数名的前缀，用来避免重名；单元格函数必须写 `=Z.JS()`，`Z` 就是命名空间 |
| 轮询 / 兜底 | 定时反复检查的保底方案；「事件」失灵时靠它隔几秒补查一次 |
| UDF | 用户自定义函数，Excel 里 `JS()` 就是这种函数 |
| LCS | 一种逐字符找相同/不同部分的比对方法，用来标红绿差异 |

> 术语在具体页面出现时，多数也带了一句括号解释；若发现某处仍然看不懂，欢迎到[文档仓库](https://github.com/hh127/inkline-docs/issues)指出页码。

# 常见问题

按现象找答案。每条都给出「先查什么」，避免盲目重装。

## 1. 重启后没有「智算墨斗」选项卡

依次检查：

1. 本地服务是否在跑：`curl http://127.0.0.1:3888/` 应返回 HTML；
2. `publish.xml` 是否真的有条目：打开 `%APPDATA%\Kingsoft\wps\jsaddons\publish.xml` 搜索「智算墨斗」；
3. 是否**完全退出** WPS（任务管理器里 `wps.exe`、`wpscloudsvr.exe` 都没了）才重启；
4. 部分版本需开启「加载 JS 加载项」开发者选项。

完整流程见[排障手册](/deploy/troubleshooting.html)。

## 2. 有选项卡，但点击按钮没反应

- 服务窗口是否被关闭？关掉窗口加载项就失效；
- `http://127.0.0.1:3888/ribbon.xml` 是否可访问（功能区定义必需独立发布）；
- 开发者工具 → JS 控制台是否有 `[智算墨斗] OnAddinLoad` 日志。

## 3. `=Z.JS()` 报 `#NAME?`

说明函数**没有被识别**，通常是：

- 加载项没真正加载（回去看第 1、2 条）；
- 输入函数时没带命名空间：必须是 `=Z.JS(...)`，纯 `=JS(...)` 不可用；
- 改完配置后没有完全重启 WPS（进程缓存）。

## 4. `=Z.JS()` 报 `#VALUE!`

这是**进步信号**：#VALUE! 说明函数已被识别并调用，问题在返回值契约（宿主把 JS 返回值转成单元格值失败）。
开发与排查看[自定义函数开发](/dev/custom-function-dev.html)；普通用户先确认表达式本身能算（如 `=Z.JS("1+1")`）。

## 5. 改了单元格，但没有审计记录

按顺序排查：

1. 该工作簿是否「启用」；
2. 配置表里该表「是否开启审计」是否为开启；
3. 全局审计总开关是否开启；
4. 改动是否落在该表的审计范围内（配置表的「审计范围(Audit)」列）；
5. 是否一次改了超大区域（**超过 5000 个单元格会跳过**，状态栏会提示）；
6. 是否在系统表（`Admin_Config` / `Log_Audit` / `Vault_*`）或隐私模式表上操作。

## 6. 新增/删除/重命名工作表后配置表不同步

表结构同步依赖平台事件；个别 WPS 版本可能只开放单元格级事件，此时靠**轮询兜底**（默认 5 秒一次Count、10 秒一次全名枚举）。
如果等待后仍不同步：切一次表或重启加载项；仍异常请反馈 WPS 版本（见[事件桥与表结构同步](/dev/events.html)）。

## 7. 统计大屏空白 / 图表不出来

大屏图表使用 ECharts CDN 资源。**断网或内网隔离时图表区会空白**（其余功能不受影响）。
处置：连接可访问 `cdn.jsdelivr.net` 的网络；内网用户自建镜像后修改 `js/lib/statistics.js` 中的脚本地址。详见[大屏的 CDN 依赖](/dev/notes/dashboard-cdn.html)。

## 8. 变色不生效

- 该表「是否开启变色」、全局变色总开关是否开启；
- 文本是否含变色跳过标记（默认 `##`）；
- 单元格/工作表是否被保护；
- 处于筛选状态时行为可能不同（软件会尽量保持屏幕刷新）；
- 只对包含括号/中英文的算式类文本生效，纯数字会跳过。

## 9. 隐私加密后原表变成 `******`

这是**设计行为**：加密 = 把原表复制到隐藏的 `Vault_<表名>` 金库 + 原表掩码 + 工作表密码保护。
通过「密码解密」还原（密码错误会失败并保留现状）。安全边界见[隐私模式与金库](/features/privacy.html)。

## 10. 一键导入旧表后按钮残留 / 配置没继承

- 旧表里的悬浮按钮等对象可能被一起复制，导入功能会清理已知按钮，其他自定义图形需手工删除；
- 旧配置继承依赖旧表的配置表结构，结构被改过时可能只继承部分；
- 导入后建议检查配置表的「工作表清单」与按表开关。

## 11. 更新了代码，但行为还是旧的

WPS 对加载项有**进程级缓存**：

1. `node build.js` 重新构建；
2. 重启本地静态服务；
3. **完全退出**所有 WPS 进程后再打开。

只关窗口不算重启。

## 12. 文件很大时很卡

已知性能边界：

- 单次改动区域 > 5000 单元格会跳过自动处理；
- 大批量变色按区域分块执行；
- 全盘统计/扫描与批注数量正相关。

建议：把审计范围限制在实际需要的工作表列区间；不要在整列上做批量粘贴；超大表分批处理。

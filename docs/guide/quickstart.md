# 快速开始

前提：已完成[安装（WPS）](/guide/install-wps.html)，功能区能看到「智算墨斗」。
下面用一张空白工作簿走完核心闭环，全程约 15 分钟。

::: tip 适用形态
本文按 **WPS JS 4.67** 编写。VBA 版按钮位置不同，但「生成配置表 → 启用 → 修改 → 看记录」的流程一致。
:::

## 第 1 步：生成配置表

点击功能区「智算墨斗 → 配置管理 → **生成配置表**」。

预期结果：工作簿里出现 `Admin_Config`（配置表）与 `Log_Audit`（审计流水）两张系统表，配置表顶部有一排控制按钮。

::: warning 系统表不要手改
`Admin_Config` 里的全局开关由软件维护，手改会被事件层拦回；需要改开关请用配置表上的按钮或侧边栏面板。
:::

## 第 2 步：启用当前文件

点击「配置管理 → **启用**」。

预期结果：状态变为启用；之后的工作簿级事件（改单元格、切表）才会被处理。
如果你有多个工作簿，需要每个工作簿单独启用。

## 第 3 步：看变色（读算式）

在任意工作表输入一条带括号的算式，例如：

```
(10+2)*3+【损耗】5%
```

预期结果：

- 括号按层级着色（默认 5 层：蓝/绿/橙/紫/深红）；
- 中英文与数字按「变色高亮颜色」着色；
- 带**变色跳过标记**（默认 `##`）的内容不着色。

没反应？检查：该表「是否开启变色」是否为开启、全局变色总开关是否开启、是否处于筛选态、单元格是否被保护。详见[变色与括号层级](/features/highlight.html)。

## 第 4 步：看审计（留痕）

先点「状态控制 → **全局审计**」确认是开启态，然后做两件事：

1. 修改刚才那个单元格，把 `(10+2)*3` 改成 `(10+3)*3`；
2. 再改一次，比如把 `3` 改成 `4`。

预期结果：单元格背景变为审计底色，批注里写入审计链（原值/新值/修改人/时间）。

## 第 5 步：看时间线

选中刚改过的单元格，点击「视图与审查 → **审计面板**」，或直接点工具栏「审计面板」。

预期结果：面板显示该单元格的完整时间线——全局总览（最终值 vs 基准点）、每个历史节点（修改人 + 时间 + 算量变化量 + 红绿差异）、基准点原值。

试试面板里的「解析」与「恢复」，理解两者作用于**该节点的新值**。

## 第 6 步（可选）：沉浸阅读与单元格函数

- 选中一条复杂算式，点「视图与审查 → **沉浸阅读**」：算式被拆成胶囊结构，悬停可看算量，点击可折叠。
- 在单元格输入 `=Z.JS("3.5*2")`，应返回 `7`（前面的 `Z.` 必须带）。详见[单元格函数](/features/custom-function.html)。

## 你刚刚完成了什么

| 能力 | 触发点 | 产物 |
| --- | --- | --- |
| 配置表 | 生成配置表 | `Admin_Config` + `Log_Audit` |
| 变色 | 输入带括号算式 | 按层级着色的文本 |
| 审计 | 修改单元格 | 单元格批注中的审计链 |
| 时间线 | 审计面板 | 可回溯、可恢复的差异视图 |
| 阅读 | 沉浸阅读 | 结构化的算式视图 |

## 收尾

- 临时不想记录：点「状态控制 → 全局审计」切到关闭，或把具体表的「是否开启审计」设为关闭。
- 彻底停用：点「配置管理 → 停用」。
- 想恢复干净工作簿：删除配置表后重新生成（会丢失历史审计记录，谨慎操作）。

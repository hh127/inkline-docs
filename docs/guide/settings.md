# 配置表与控制台

所有行为都由工作簿里的 `Admin_Config` 驱动。本文按参数分组解释每个键，并说明哪些开关不能手改、改完何时生效。

## 怎么打开

- **WPS JS 版**：功能区「智算墨斗 → 配置管理 → 生成配置表」生成；之后可直接切到 `Admin_Config` 工作表查看，修改请优先用按钮/侧边栏面板。
- **Excel VBA 版**：工作簿内的控制面板按钮行（导入旧表、同步/重置配置、看历史/阅读开关、全表批量变色、清除审计标记、隐私遮蔽、导出、生成大屏等）。

## 全局参数（按分组）

### 核心安全与总控（锁定，不可手改）

| 键 | 默认 | 作用 |
| --- | --- | --- |
| 是否启用智算墨斗 | 开启 | 总开关；关闭后暂停全部功能，配置表保留 |
| 全局变色总开关 | 开启 | 工作簿级变色开关 |
| 全局审计总开关 | 开启 | 工作簿级审计开关 |

### 悬浮面板 UI（锁定）

| 键 | 默认 | 作用 |
| --- | --- | --- |
| 显示看历史悬浮按钮 | 关闭 | 点选审计单元格时悬浮显示入口（VBA 版特性） |
| 显示阅读模式悬浮按钮 | 关闭 | 点选变色单元格时悬浮显示入口（VBA 版特性） |

> WPS JS 版用 Ribbon + 侧边栏替代表内悬浮按钮，这两项在 WPS 版不产生悬浮控件。

### 审计追踪与日志

| 键 | 默认 | 说明 |
| --- | --- | --- |
| 审计背景颜色 | `#87CEEB` | 有审计记录单元格的底色 |
| 保留最近批注数 | 5 | 每格最多保留几条历史；0 表示不限制 |

### 通用变色与排版

| 键 | 默认 | 说明 |
| --- | --- | --- |
| 变色高亮颜色 | 红色 | 中文与数字的高亮色 |
| 变色跳过标记 | `##` | 含此标记的文本跳过变色 |
| 默认字体名称 | 微软雅黑 | 非变色文字字体 |
| 默认字体大小 | 9 | 非变色文字字号 |
| 默认字体颜色 | 黑色 | 非变色文字颜色 |

### 多级括号渲染

| 键 | 默认 | 说明 |
| --- | --- | --- |
| 括号强制字体 | 黑体 | 括号专用字体 |
| 括号最大嵌套层级 | 5 | 超过按第 1 层循环 |
| 括号最小字号 | 6 | 最深层字号下限 |
| 括号颜色_1～5 层 | 蓝/绿/橙/紫/深红 | 可逐层改色（颜色盒） |

### 项目信息与大屏

| 键 | 默认 | 说明 |
| --- | --- | --- |
| 项目名称 | 智算墨斗 · 结算审计数据中台 | 大屏顶部主标题 |
| 项目主审人 | 空（默认系统用户名） | 大屏右上角展示 |

### 异常靶点阈值

| 键 | 默认 | 说明 |
| --- | --- | --- |
| 异常靶点偏离度阈值 | 0.05 | 偏差率超过 5% 进入异常靶点列表 |
| 异常靶点绝对量差阈值 | 500 | 量差绝对值超过 500 进入异常靶点列表 |

## 按表开关（工作表清单区）

| 列 | 说明 |
| --- | --- |
| 工作表名称 | 自动同步（含新增/删除/重命名，见[事件桥](/dev/events.html)） |
| 审计范围(Audit) | 参与审计的列/区域，建议只覆盖实际需要复核的列 |
| 变色范围(Color) | 参与变色的列/区域 |
| 是否开启审计 | 单表开关 |
| 是否开启变色 | 单表开关 |
| 隐私遮蔽模式 | 由隐私加密/解密自动回写 |

## 锁定规则（为什么手改会被弹回）

以下 5 个开关被标记为「系统独占修改」：

`是否启用智算墨斗`、`全局变色总开关`、`全局审计总开关`、`显示看历史悬浮按钮`、`显示阅读模式悬浮按钮`

保护是双保险：工作表 Protect + SheetChange 事件拦截。手动写入会被恢复为系统值，并触发配置重载。
需要切换请用 Ribbon 的开关按钮或侧边栏面板。

## 改完何时生效

修改配置表（按钮改或合法的手改）会触发 `SheetChange` 分支：系统写入不拦截 → 受保护开关校验 → 重载配置。
因此**保存即生效**，不需要重启 WPS；个别情况下若界面状态没刷新，切换一次开关或切表即可。

## 颜色盒怎么用

配置表里带颜色盒的参数（如审计背景颜色、括号颜色），值以**单元格填充色**表示：H 列即色块，修改填充色后保存即可。读取时取该单元格的 `Interior.Color`，空/无填充时回退默认色。

## 常见误操作

| 操作 | 后果 | 正确做法 |
| --- | --- | --- |
| 手改全局审计开关 | 被拦回原值 | 用 Ribbon 状态控制按钮 |
| 删除 `Admin_Config` 后不重新生成 | 全部功能停止 | 重新「生成配置表」 |
| 把审计范围设成整列 | 大表卡顿、记录噪音多 | 限定到实际列区间 |
| 新加表没开按表开关 | 新表不审计/不变色 | 在配置表打开对应开关 |
| 用 xlsx 保存 | VBA 版代码与事件丢失 | 始终保存为 `.xlsm` |

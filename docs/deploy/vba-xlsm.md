# Excel VBA 分发

适用于在**多台 Excel 机器**上使用 v4.66。个人安装见[安装（VBA）](/guide/install-vba.html)。

::: warning 冻结版本
v4.66 是最后一个 VBA 制品，不再更新。新项目建议直接用 [WPS JS 4.67](/guide/install-wps.html)。
:::

## 分发什么

| 文件 | 用途 | 分发方式 |
| --- | --- | --- |
| `智算墨斗v4.66.xlsm` | 空白工作簿（含宏与配置） | 作为**模板**复制给每位使用者 |
| `案例演示文件v4.66.xlsm` | 演示数据 | 可选，培训用 |

不要把某个真实项目的文件当模板分发——审计批注、隐私状态、配置都会一起带出去。

## 分发步骤

1. **准备工作簿**：打开模板 → 生成配置表 → 按项目需要改配置（项目名称、审计/变色范围）→ 另存为项目文件；
2. **放到受控位置**：统一目录（如 `\\server\share\造价工具\`）或每人本地固定目录；
3. **加入受信任位置**（推荐）：
   - Excel → 文件 → 选项 → 信任中心 → 信任中心设置 → 受信任位置 → 添加网络/本地路径；
   - 企业环境可用组策略统一下发受信任位置（视 IT 策略而定）；
4. **验证**：打开项目文件不再出现"宏已被禁用"拦截，功能区/控制面板正常；
5. **培训两条铁律**：始终保存为 `.xlsm`；不要启用「共享工作簿」。

## 宏安全建议

| 做法 | 评价 |
| --- | --- |
| 受信任位置 + 每次手动「启用内容」 | ✅ 推荐 |
| 启用所有宏 | ⚠️ 仅受控机器临时用，不建议长期 |
| 禁用所有宏并通知 | ❌ 功能不可用 |
| 从网络位置直接打开（未解除锁定） | ❌ 会进受保护的视图，事件不工作 |

文件来自网络/邮件时，先右键 → 属性 → 解除锁定，再打开。

## 版本与签名

- v4.66 制品**没有数字签名**：分发时请通过可信渠道，并在单位内说明来源与校验方式（如文件哈希）；
- 需要正式分发时，建议由单位用自有证书对 xlsm 签名后再下发；
- 版本号口径以仓库 `releases/` 为准（只有 4.66），不要拿 4.67 的源码版本号去对 VBA 制品。

## 升级与回滚

VBA 线已冻结，不存在功能升级；如需替换文件：

1. 让使用者保存并关闭项目文件；
2. 备份旧版工作簿（含审计批注）；
3. 用新版模板替换**模板**，已生成的项目文件不动；
4. 回滚 = 恢复旧模板文件。

::: tip 不要把"替换模板"理解成"替换项目文件"
项目文件里存着审计链与隐私状态，替换会丢数据。
:::

## 共享与多人协作限制

- 启用「共享工作簿」会关闭部分事件，审计与变色都会失效——**不要用共享工作簿做多人同时编辑**；
- 建议一人主审：由主审在自己的项目文件上操作，其他人只读或拿导出副本；
- 需要多人并行时，改用 [WPS 加载项 + 内网部署](/deploy/wps-addin.html) 的分工方式，或分文件处理后再合并。

## 常见问题

| 现象 | 处置 |
| --- | --- |
| 每台机器都提示宏被禁用 | 统一加受信任位置；检查文件是否被标记为来自网络 |
| 部分机器打开后按钮不全 | 检查 Excel 位数/版本；确认不是受保护视图；确认工具栏未被折叠 |
| 另存后功能消失 | 保存成了 `.xlsx`，改回 `.xlsm` 并重新启用宏 |
| 共享后审计不记录 | 关闭共享工作簿；改为单人主审 |
| 杀毒软件拦截 | 将工具目录加入白名单；用哈希说明文件来源 |

# 踩坑专栏索引

重点讲清楚"为什么当时那么想是错的"，方便你在遇到相似现象时少走弯路。

- 每篇结尾都有「你也遇到了？」检查清单，按顺序勾选能排除大部分常见原因；
- 涉及参数/阈值的，以源码为准（文中会给出文件路径）；
- 不写内部人名、项目名与机器路径。

# 已知限制

限制不等于 bug。本页把「暂时做不到」「平台不给」「我们有意不做」分开列清楚，避免把它们当成故障反复排查。

## 版本与分发

| 限制 | 影响 | 现状 / 缓解 |
| --- | --- | --- |
| 4.67 **没有安装包** | 不能一键装 | 按[安装（WPS）](/guide/install-wps.html)用源码部署 |
| VBA 线已冻结（4.66） | 不再有新功能 | 新项目用 WPS JS 版 |
| `src/` 是转写副本，有已知退化 | 不能用来重建部署文件 | 以 `src-xlsm-v4.67/` 为基线，见[VBA 架构](/dev/architecture-vba.html) |

## 平台能力

| 限制 | 影响 | 现状 / 缓解 |
| --- | --- | --- |
| 表结构事件是否全部触发**待真机确认** | 新建/删除表可能延迟同步 | 轮询兜底（约 5～10 秒），见[事件桥](/dev/events.html) |
| 不同 WPS 版本加载项能力有差异 | 个别版本需手动开启「加载 JS 加载项」 | 见[排障手册](/deploy/troubleshooting.html) |
| WPS 进程缓存 | 改了代码不生效 | 必须完全退出所有 WPS 进程 |
| JS 宏编辑器不支持单元格 UDF | `=Z.JS()` 只能在官方加载项用 | 见[自定义函数开发](/dev/custom-function-dev.html) |

## 离线与外部依赖

| 限制 | 影响 | 现状 / 缓解 |
| --- | --- | --- |
| 统计大屏依赖 ECharts CDN | 断网/内网隔离时图表空白 | 其余功能正常；内网可自建镜像，见[大屏的 CDN 依赖](/dev/notes/dashboard-cdn.html) |
| 内网部署需静态服务 | 不能 `file://` 直接打开 | 见[WPS 加载项部署](/deploy/wps-addin.html) |

## 数据与安全边界

| 限制 | 影响 | 现状 / 缓解 |
| --- | --- | --- |
| 隐私模式**不是加密** | 不能抵御专业工具还原 | 高敏感文件叠加文件级加密，见[隐私模式](/features/privacy.html) |
| 单次改动 > 5000 单元格跳过自动处理 | 批量粘贴不产生审计记录 | 分批操作，见[实时审计](/features/audit.html) |
| 批注即审计历史 | 删批注 = 删历史 | 先导出审查版再清理 |
| 「恢复」「清除审计标记」不可撤销 | 误操作无法回退 | 操作前备份/导出 |
| 审计记录依赖本机事件 | 只读/受保护/共享工作簿可能不记录 | 用受控环境，避免共享工作簿 |

## 有意取舍（不是缺陷）

| 取舍 | 原因 | 替代 |
| --- | --- | --- |
| WPS 版不做表内悬浮按钮 | 平台限制 + Ribbon/侧边栏已覆盖入口 | Ribbon + 任务窗格 |
| WPS 版不做快捷键体系 | 与宿主快捷键冲突风险 | Ribbon 按钮 |
| WPS 版不做大屏落盘 | 任务窗格内渲染更符合加载项形态 | 任务窗格/侧边栏大屏 |
| 导入/隐私批量用编号多选 | WPS JS 无模态窗体 API | 功能等价的多选提示 |

## 工程与文档

| 限制 | 影响 | 现状 / 缓解 |
| --- | --- | --- |
| 宿主绑定路径无法单测 | 加密/导入/导出只能真机验证 | 核心逻辑纯函数化，真机清单见开发日志 |
| 仓库暂无 CI | 依赖本地测试与提交钩子 | 建议接入 Actions（见[构建与测试](/dev/build-test.html)） |
| 部分文档页仍在建设 | 以源码为准 | 见[版本更新](/changelog/)与各页状态提示 |

## 如何报告问题

1. 先对照本页与[常见问题](/guide/faq.html)；
2. 记录：WPS/Excel 版本、Windows 版本、操作步骤、日志前缀片段（`[智算墨斗]` / `[智算墨斗][函数]`）；
3. 到 [Issues](https://github.com/hh127/SmartQuant-InkLine/issues) 提交，附脱敏后的信息。

> 安全提醒：贴日志前删掉内网地址、本机路径、项目名与金额。

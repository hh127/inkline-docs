# 沉浸阅读

::: tip 适用形态
WPS JS 加载项 4.67 ✅ ｜ Excel VBA 4.66 ✅（VBA 版为窗体 WebBrowser，WPS 版为任务窗格/侧边栏）
:::

## 它解决什么问题

一条 200 字符的手算算式，即使有变色，也仍然是一条长文本。
沉浸阅读把它拆成**横向胶囊**：数字、运算符、括号、中文注释各自成为可交互单元；可以隐藏中文注释、悬停看局部算量、按模块折叠，最后给出两位小数的结果。

## 界面能力

| 能力 | 说明 |
| --- | --- |
| 横向透视 | 算式按 token 拆成胶囊，括号层级用不同底色 |
| 隐藏中文注释 | 一键切换"注释透视"，只看数学结构 |
| 悬停算量 | 鼠标停在括号/模块上显示局部计算结果 |
| 点击折叠 | 模块可折叠，长算式按需展开 |
| 模块解构 | 自动识别顶层 `+` / `-` 结构，生成「增加项 / 扣减项」卡片 |
| 结果展示 | 纯数值定点两位；错误串（`#VALUE!` 等）原样透出，不强转数字 |
| 实时跟随 | 面板跟着当前选中单元格刷新（约 800ms 指纹比对，避免重复渲染） |
| 历史快照 | 从审计时间线打开某一版时，标记「历史版本快照」，**固定不跟随**当前格 |

## 操作步骤

1. 选中包含算式的单元格；
2. 点击「视图与审查 → **沉浸阅读**」（WPS 也可从侧边栏打开历史/阅读入口）；
3. 阅读面板显示：最终计算结果 → 原始算式胶囊 → 模块解构卡片；
4. 用面板顶部开关「隐藏中文注释」切换透视；
5. 点击模块卡片上的折叠/恢复按钮查看局部；
6. 从审计面板的某个历史节点进入时，面板显示的是**该历史版本**（有红色徽标），不会跟着你切换单元格。

## 前置条件

- 单元格内容是**文本类算式**（含中文、括号、运算符），纯数字没有阅读价值；
- 需要显示算量/结果时，求值依赖[计算引擎](/features/calc.html)；清洗会跳过默认 `##` 标记之后的内容；
- 历史快照需要该单元格已有审计记录。

## 参数与开关

| 名称 | 默认 | 说明 |
| --- | --- | --- |
| 括号颜色_1～5 层 | 蓝/绿/橙/紫/深红 | 胶囊/括号配色 |
| 括号强制字体 / 最小字号 | 黑体 / 6 | 胶囊文字样式 |
| 括号最大嵌套层级 | 5 | 超过循环回第 1 层 |
| 变色跳过标记 | `##` | 清洗与着色时跳过 |
| 保留最近批注数 | 5 | 决定能打开多少个历史快照 |

## 结果与判定

- 面板顶部结果与单元格计算值一致（两位小数）→ 解析正确；
- 模块卡片的增加项/扣减项之和等于结果 → 结构识别正确；
- 切换单元格时面板内容跟着变；历史快照不跟 → 跟随逻辑正确。

## 边界与注意事项

- 只解析**文本表达式**，不处理真正的 Excel 公式引用语义（引用会先按单元格值代入清洗规则）；
- 超长算式的胶囊很多，滚动与折叠是主要阅读手段；
- 面板里的「恢复」类按钮是**写回操作**（把面板展示的算式/模块写回单元格），执行前确认；
- 隐私模式下原表是 `******`，阅读面板没有可读内容，需先解密；
- 历史快照固定在打开时的版本，不会因继续修改而更新。

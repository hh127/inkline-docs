# 变色与括号层级

::: tip 适用形态
WPS JS 加载项 4.67 ✅ ｜ Excel VBA 4.66 ✅（差异见[双实现能力矩阵](/dev/parity.html)）
:::

## 它解决什么问题

手算量底稿里的长算式，括号一多就难读：哪一层括号配哪一层、哪个数字是注释、哪里漏了乘号。
「变色」功能会按括号嵌套层级给文本着色，并把中文说明与数字区分开——不用改公式，肉眼就能顺着颜色读结构。

## 效果规则

| 内容 | 处理 |
| --- | --- |
| 括号（含全角括号） | 按嵌套层级着色，默认 5 层：蓝 → 绿 → 橙 → 紫 → 深红；超过 5 层按第 1 层循环 |
| 中英文与数字 | 用「变色高亮颜色」着色 |
| 中文说明文字 | 保持默认字体/字号（默认微软雅黑 9 号） |
| 含跳过标记（默认 `##`） | 整格跳过，不着色 |
| 纯数字 / 空白 | 跳过（性能优化，不做无意义重绘） |

括号层级对应的字体由「括号强制字体」控制（默认黑体），最深层受「括号最小字号」限制（默认 6）。

## 触发条件

一次改动触发变色，需要同时满足：

1. 工作簿已启用；
2. 全局变色总开关开启；
3. 目标表「是否开启变色」为开启；
4. 改动落在该表「变色范围(Color)」指定的区域内；
5. 不是系统表 / 隐私表，且单次改动不超过 5000 单元格。

## 操作步骤

1. 生成配置表后，在配置表里找到目标表那一行，把「是否开启变色」设为开启；
2. 确认「全局变色总开关」为开启（Ribbon 状态控制里的开关按钮也可切换）；
3. 在变色范围内输入或修改算式，例如 `(5.51+0.1)*2+【损耗】5%`；
4. 观察括号与文字按层级着色；需要跳过某格时在文本里加入 `##`。

## 参数与开关

| 名称 | 默认 | 说明 |
| --- | --- | --- |
| 全局变色总开关 | 开启 | 工作簿级总开关 |
| 是否开启变色（按表） | 生成时自动 | 单表开关 |
| 变色范围(Color) | 按表生成 | 限定着色的列/区域，缩小可提速 |
| 变色高亮颜色 | 红色 | 中文与数字的高亮色 |
| 变色跳过标记 | `##` | 含此标记的整格跳过 |
| 默认字体名称 / 大小 / 颜色 | 微软雅黑 / 9 / 黑 | 非变色文字的样式 |
| 括号强制字体 | 黑体 | 括号专用字体 |
| 括号最大嵌套层级 | 5 | 超过后按第 1 层循环 |
| 括号最小字号 | 6 | 深层括号的字号下限 |
| 括号颜色_1～5 层 | 蓝/绿/橙/紫/深红 | 每层颜色可单独修改 |

## 结果与判定

- 括号颜色随层级变化、层级越深颜色越靠后 → 成功；
- 修改算式后颜色重新计算（不是残留旧色）→ 成功；
- 添加 `##` 后整格不再着色 → 跳过标记生效。

## 边界与注意事项

- **筛选状态**：软件会尽量保持屏幕刷新，避免 WPS 把这一批颜色"吞掉"，但极端情况下可能出现闪烁；
- **保护的工作表**：写入颜色会失败，需先取消保护；
- **大区域批量**：按区域分块执行，超大区域可能耗时；超过 5000 单元格的改动直接跳过自动处理；
- 变色只改**显示样式**（字体颜色/字体/字号），不改单元格值与公式；
- 若与其他条件格式/宏冲突，以最后写入者为准。

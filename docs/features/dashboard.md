# 统计大屏

::: tip 适用形态
WPS JS 加载项 4.67 ✅（任务窗格内渲染）｜ Excel VBA 4.66 ✅（可落盘为独立 HTML）
:::

## 它解决什么问题

结算审计结束时，领导要看的不是某一格，而是**全盘画像**：一共改了多少、净增净减多少、哪些表争议最多、谁在改、什么时候改、哪些量异常偏离。
统计大屏扫描所有审计批注，把这些指标聚合成一屏可视化。

## 指标口径（务必先看）

数据来源是**审计批注**（只有含 `--- 修改于` 的批注才计入）：

| 指标 | 口径 |
| --- | --- |
| 已审计单元格数 | 有机器审计批注的单元格数 |
| 有效争议数 | 基准点算量与当前算量**都是数值且不相等** |
| 修改动作总数 | 所有历史日志条数合计 |
| 核增合计 / 核减合计 | 逐格净变化量（当前算量 − 基准算量），正数进核增、负数进核减 |
| 按表统计 | 每张表的审计数、有效争议、修改次数、核增/核减、最早/最晚修改日期 |
| 作者画像 | 按 `修改人` 统计动作数 |
| 干预趋势 | 按修改日期统计每日修改频次 |
| 异常靶点 | 偏离度 ≥ 阈值（默认 0.05）或绝对量差 ≥ 阈值（默认 500）的单元格 |

## 图表构成

| 组件 | 内容 |
| --- | --- |
| 总览卡片 | 项目名称、主审人、审计单元格数、有效争议、核增/核减合计 |
| 饼图 | 各工作表「修改次数」占比 |
| 柱状图 | 多方博弈画像：按作者动作数排名 |
| 折线图 | 审计干预时间轴趋势（每日修改频次） |
| 异常靶点列表 | 超过阈值的单元格（表名/地址/偏离度/量差） |

## 操作步骤

1. 确认审计链路已工作（有批注记录）；
2. 填写配置表里的「项目名称」「项目主审人」（大屏展示用）；
3. 按需调整「异常靶点偏离度阈值 / 绝对量差阈值」；
4. 点击「生成统计大屏」（Ribbon 或侧边栏「📊统计大屏」；VBA 版对应宏 `Export_Comprehensive_Report`）；
5. 生成后在大屏视图查看；数据变化后需**重新生成**才会刷新。

## 前置条件

- 工作簿已启用，且审计记录存在；
- 能访问 **ECharts 图表库的在线地址**（`cdn.jsdelivr.net`）。断网/内网隔离时图表区会空白，其余数据不受影响；
- 大屏是在侧边栏里嵌套的一个独立小窗口（iframe）中显示的，部署时要确保 `ui/index.html` 已发布（内网部署常见漏项）。

## 参数与开关

| 名称 | 默认 | 说明 |
| --- | --- | --- |
| 项目名称 | 智算墨斗 · 结算审计数据中台 | 大屏主标题 |
| 项目主审人 | 空（默认系统用户名） | 大屏右上角展示 |
| 异常靶点偏离度阈值 | 0.05 | 5% 偏差进入异常靶点 |
| 异常靶点绝对量差阈值 | 500 | 绝对量差超过 500 进入异常靶点 |
| 审计范围(Audit) | 按表生成 | 只统计范围内的批注 |

## 结果与判定

- 总览的核增/核减合计与人工抽样一致 → 口径正确；
- 饼图/柱状图/趋势图有数据 → 渲染正常（空白先查网络或 CDN）；
- 异常靶点数量与阈值调整联动 → 阈值生效。

## 边界与注意事项

- **依赖外部图表库（CDN）**：离线环境图表空白是已知限制，详见[大屏的 CDN 依赖](/dev/notes/dashboard-cdn.html)；
- 只统计含机器日志的批注；纯手工批注不计入；
- 全盘扫描与批注数量正相关，超大工作簿生成需要等待；
- 大屏是**生成时的快照**，不会自动刷新；
- 隐私表内容是 `******`，其审计数据在解密前不可统计；
- 统计结果用于内部管理，不要直接作为对外结算依据（口径以合同与审计底稿为准）。

# 清除审计标记

::: tip 适用形态
WPS JS 加载项 4.67 ✅ ｜ Excel VBA 4.66 ✅（差异见[双实现能力矩阵](/dev/parity.html)）
:::

## 它解决什么问题

审计做完了，底稿要交给下一环节，但单元格上全是批注和审计底色——既难看也泄露内部过程。
清除审计标记会把**机器日志**清掉，同时**保留你自己写的用户批注**，并清除审计底色。

## 批注处理规则（按批注类型区分）

| 批注类型 | 判断依据 | 处理 |
| --- | --- | --- |
| 纯手工批注 | 不含 `--- 修改于` | **原样不动** |
| 机器日志 + 用户批注 | 含 `--- 修改于` 且含 `--- 用户批注 ---` | 截取用户手工部分**重写**批注，并尽量恢复批注框样式 |
| 纯机器日志 | 含 `--- 修改于`，无用户内容 | **删除批注** |

审计底色清除：在「审计范围 ∩ UsedRange」内逐格比对颜色，等于审计背景色的单元格改为无填充。
为控制成本设置了单元格上限，超限时只清审计范围并给出提示。

系统表（`Admin_Config` / `Log_Audit` / `Vault_*`）整体跳过。

## 操作步骤

1. **先导出审查版**（清除不可撤销，见下方警告）；
2. 打开配置表控制台，执行「清除审计标记」（宏 `Clear_All_Audit_Marks`；VBA 版为控制面板按钮）；
3. 确认提示；
4. 完成后抽查：机器批注消失、用户批注仍在、审计底色清除。

## 参数与开关

| 名称 | 作用 |
| --- | --- |
| 审计背景颜色 | 判定哪些底色属于审计痕迹 |
| 审计范围(Audit) | 决定清底色的范围 |
| 单元格上限 | 防止超大表清理过慢的安全阀 |
| 系统表过滤 | 自动跳过系统表 |

## 结果与判定

- 搜索 `--- 修改于` 无结果 → 机器日志已清；
- 搜索 `--- 用户批注 ---` 对应的文字仍在 → 用户内容保留；
- 单元格恢复为无填充 → 底色已清。

## 边界与注意事项

::: danger 不可撤销
清除后审计链与底色无法恢复。执行前请先[导出审查版](/features/export.html)或备份工作簿。
:::

- 批注框的物理样式（大小/位置）恢复是**尽力而为**：WPS 加载项不一定提供调整批注框形状的接口，不能保证 100% 还原；
- 只清「审计范围 ∩ UsedRange」内的底色，范围外的手工底色不会被动；
- 大表可能触发上限提示，清理范围会收窄；
- 隐私表的批注在加密时已被清除，无需再清；
- 清理后不等于"清洁交付"：仍需按[导出交付版](/features/export.html)做公式静态化与痕迹剥离。

# 隐私模式与金库

::: tip 适用形态
WPS JS 加载项 4.67 ✅ ｜ Excel VBA 4.66 ✅（差异见[双实现能力矩阵](/dev/parity.html)）
:::

::: danger 先记住结论
隐私模式**不是密码学加密**。它是「隐藏金库 + 内容掩码 + 工作表密码保护」，防的是误看和随手转发，
**不能**抵御专业工具还原。真正的强加密请用文件级加密（加密压缩包 / 加密盘 / 文档加密系统）。
:::

## 它解决什么问题

交付前、评审前、投屏前，工作簿里总有些表不能给无关的人看到（成本、报价、敏感工程量）。
隐私模式把整张表"藏起来"：原表只剩 `******`，真实内容在隐藏金库；需要时用密码还原。

## 加密时发生了什么

1. 把当前表**复制**一份到工作簿末尾，命名为 `Vault_<表名>`，并设为 `VeryHidden`（普通"取消隐藏"看不到）；
2. 清空原表的所有批注（避免审计痕迹泄露）；
3. 对原表 `UsedRange` 逐格写入 `******`：
   - 跳过公式单元格；
   - 合并单元格只写左上角（避免"无法更改合并单元格"导致中断）；
   - 每格独立容错；
4. 用你输入的密码保护原表（`Protect`）；
5. 在配置表「隐私遮蔽模式」列回写为已加密。

整个过程中事件、屏幕刷新、计算模式会被临时关闭，结束后恢复；失败也会恢复环境，不会把工作簿留在半关闭状态。

## 解密时发生了什么

1. 用密码解除原表保护；
2. 把金库内容复制回原表；
3. 恢复列宽（宿主支持 `PasteSpecial xlPasteColumnWidths` 时；不支持则降级）；
4. 删除金库；
5. 配置表状态回写为正常。

## 操作步骤

### 单表

1. 激活要加密的表；
2. 点击「交付与安全 → **隐私加密**」，输入密码；
3. 原表变为 `******`，金库表出现（隐藏）；
4. 需要还原时点「**密码解密**」，输入同一密码（错误会失败并保留现状）。

### 批量（推荐用于多表交付）

1. 打开隐私菜单/侧边栏「🔒批量加密」或「🔓批量解密」；
2. 面板列出所有业务表及当前状态，按编号多选（`*` 全选）；
3. 一次输入密码；
4. 系统自动跳过"意图与现状相同"的表；
5. 完成后汇总成功/失败数量（失败通常是密码错误或数据异常）。

::: tip 隐私表不可直接编辑
在隐私模式下改单元格，事件层会**撤销**这次修改。要编辑必须先解密。
:::

## 参数与开关

| 名称 | 说明 |
| --- | --- |
| 隐私遮蔽模式（配置表列） | 每张表的加密状态，软件自动回写 |
| 密码 | 由宿主工作表保护机制校验；不是自建加密密钥 |
| 系统表过滤 | `Admin_Config`、`Log_Audit`、`Vault_*` 不参与加解密 |

## 结果与判定

- 原表可见内容变为 `******`，且出现隐藏的 `Vault_<表名>` → 加密成功；
- 解密后内容与加密前一致，列宽恢复 → 解密成功；
- 配置表对应行状态正确 → 状态回写成功。

## 安全边界（请如实告知使用者）

| 能防 | 不能防 |
| --- | --- |
| 投屏/演示时被看到 | 专业恢复工具取消隐藏、解除工作表保护 |
| 文件被随手转发后直接查看 | 拿到文件的人用脚本提取金库 |
| 误操作改到敏感数据 | 丢失密码后的强制还原（不要承诺） |

因此：**密码要单独渠道传递**；高敏感文件叠加文件级加密；不要把隐私模式当合规加密方案写进制度。

## 注意事项

- 原表批注会被清除（这是为了不留审计痕迹），需要保留审计信息请先**导出审查版**；
- 隐藏金库会让文件体积明显增大（相当于多一份表）；
- 大表逐格掩码耗时较长，属正常；
- 忘记密码时，数据仍在金库里，但软件不提供绕过保护的功能；
- 导出外部交付版时会**物理剥离**加密表与金库（见[导出](/features/export.html)）。

# 一键导入旧表

::: tip 适用形态
WPS JS 加载项 4.67 ✅ ｜ Excel VBA 4.66 ✅（VBA 版为多选窗体，WPS 版为编号多选提示）
:::

## 它解决什么问题

手工把旧项目的工作表搬进新模板，容易漏表、丢格式、配置全部重填。
一键导入会：选择源文件 → 多选工作表 → 整表复制到当前工作簿 → 清理旧版残留 → 按规则继承旧配置。

## 导入流程

1. 选择源工作簿文件（系统文件对话框）；
2. 列出可导入的工作表：**排除** `Admin_Config`、`Log_Audit`、`Vault_*`；
3. 按编号多选（`*` 全选；支持逗号/空格分隔）；
4. 逐表整表复制到当前工作簿末尾；
5. 清理旧版悬浮按钮残留（`AuditFloatBtn` / `ReadFloatBtn`）；
6. 询问是否继承旧配置；
7. 合并旧配置并复位宿主环境。

::: tip 为什么是"编号多选"
WPS JS 加载项没有模态窗体 API，因此用编号列表 + 多选文本替代 VBA 的 ListBox 多选，功能等价（列表、多选、全选）。
:::

## 配置继承规则（重点）

### 工作表级配置（A:F 区，按表名匹配）

| 列 | 规则 |
| --- | --- |
| A 工作表名称 | 匹配键 |
| B / C（审计范围 / 变色范围） | 旧值**非空**才覆盖新值 |
| D / E（是否开启审计 / 变色） | 归一化后**无条件**写回 |
| F（隐私状态） | 旧值**非空**才归一写回 |

旧表里匹配不上的行跳过；新版本独有的参数保留默认值。

### 全局参数（G:H 区，按参数名匹配）

- 按 G 列参数名对位；
- 旧值为**空单元格**时跳过（空串仍视为有值）；
- 「颜色」类参数写底色并清空文本；
- 其余参数归一为布尔/数值后写回。

## 操作步骤

1. 在**目标工作簿**里点「配置管理 → 生成配置表」（确保有新配置表）；
2. 点击「一键导入旧表」（VBA 版为控制面板按钮）；
3. 选择旧文件 → 按提示选表（如 `1,3,5` 或 `*`）；
4. 选择是否继承旧配置；
5. 等待完成提示，检查：
   - 表是否齐全；
   - 配置表按表开关是否符合预期；
   - 旧表带来的批注是否需要清理。

## 结果与判定

- 目标工作簿出现所选工作表，内容/格式与源表一致 → 复制成功；
- 配置表对应行的范围与开关被旧值覆盖 → 继承成功；
- 提示里没有失败表名 → 全部复制成功。

## 边界与注意事项

- **整表复制**会连同格式、公式、批注一起带过来（旧审计批注也会进来，介意请先清理）；
- 工作表重名时宿主会自动改名为「原名 (2)」，软件用**真实新表名**清理按钮，不会误伤同名的原表；
- 隐私表（`Vault_*`）不参与导入，导入后隐私状态需重新处理；
- 旧配置结构被大改过时，可能只有部分参数能匹配上；
- 导入后建议保存为 `.xlsm`（如后续还要用 VBA）或按项目规范保存；
- 大工作簿整表复制耗时较长，期间不要操作宿主。

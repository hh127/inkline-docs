# 导出审查版与交付版

::: tip 适用形态
WPS JS 加载项 4.67 ✅ ｜ Excel VBA 4.66 ✅（差异见[双实现能力矩阵](/dev/parity.html)）
:::

## 它解决什么问题

同一个项目文件往往要导出两种东西：

- **内部审查版**：给复核/归档用，要保留审计信息（谁改的、改了几次）；
- **外部交付版**：给甲方/咨询/下一环节用，要干净、可打开、不带内部痕迹与插件依赖。

导出过程全程在**临时副本**上操作，原表一个单元格都不会被改动。

## 两种版本的区别

| 处理 | 内部审查版 | 外部交付版 |
| --- | --- | --- |
| 审计底色 | 清理 | 清理 |
| 机器审计批注 | 恢复可见，可保留最近 N 条 | 剥离（保留用户手工批注） |
| 纯用户批注 | 保留 | 保留 |
| 隐私加密表 | 保留 | **物理剥离**（连同 `Vault_` 金库） |
| 公式静态化 | 做 | 做 |
| 输出格式 | 独立 `.xlsx` | 独立 `.xlsx` |
| 原表 | 零改动 | 零改动 |

## 执行流程（源码行为）

```text
SaveCopyAs 临时副本
   → 打开副本
   → 清洗副本（清底色 / 批注处理 / 外部版剥离加密表 / 公式静态化）
   → 另存为独立 xlsx
   → 关闭副本 → 删除临时文件
   → 恢复事件与计算模式
```

任意一步失败或用户取消，都会走 `finally` 清理临时文件并恢复环境。

## 公式静态化（交付版关键）

交付文件脱离插件环境后，`=Z.JS("...")` 必然变成 `#NAME?`。因此导出时会把这类公式：

1. 能内联的 → 直接改写为内联数学式（交付文件可原生重算）；
2. 无法内联的（含单元格引用、改写失败）→ 降级为已算好的值，彻底消灭 `#NAME?`；
3. 如果回读发现公式仍在（值兜底未生效），会标红提醒交付者检查。

## 操作步骤

1. 保存当前工作簿；
2. 需要审查版：点「交付与安全 → **导出审查版**」；需要对外交付：点「**外部交付版**」（VBA 版对应宏 `Export_Audit_Version` / `Export_Internal_Version`）；
3. 选择保存位置与文件名（默认带时间戳）；
4. 等待提示"导出完成"，核对保存路径与清洗统计；
5. 打开导出文件抽查：应能正常打开、无 `#NAME?`、无内部审计痕迹（外部版）。

## 参数与开关

| 名称 | 说明 |
| --- | --- |
| 保留最近日志条数 | 仅内部版生效；`0` 表示不额外截断 |
| 变色跳过标记（`##`） | 公式静态化清洗时复用 |
| 系统表 | `Admin_Config` / `Log_Audit` / `Vault_*` 不参与清洗 |
| 输出格式 | `.xlsx`（不带宏，避免接收方宏安全拦截） |

## 结果与判定

- 原工作簿修改时间/内容未变 → 零改动成立；
- 导出文件能独立打开，抽查 `=Z.JS` 位置显示数值或数学式 → 静态化成功；
- 外部版中搜索不到 `--- 修改于` → 机器痕迹已剥离；
- 外部版中加密表消失、无 `Vault_` → 物理剥离成功。

## 边界与注意事项

- **不可撤销**：导出的清洁版本无法找回被剥离的机器批注；需要完整历史请保留原表或导出审查版；
- 输出 `.xlsx`，接收方不需要安装任何插件；
- 大工作簿导出耗时较长（复制 + 全表清洗）；
- 外部版剥离加密表后，如果业务上需要这些数据，应先用[密码解密](/features/privacy.html)；
- 若怀疑公式静态化失败，看是否有标红单元格（导出结果会提示）；
- 杀毒软件可能拦截临时文件创建，必要时把工具目录加入白名单。
